# The Long Drive × Garry's Mod

A planned, separate Garry's Mod gamemode that brings The Long Drive's real vehicles and items into Garry's Mod, with movement and driving intended to feel as close to The Long Drive as the games allow.

## Intended first version

- Spawn on the Garry's Mod map the player selects.
- Support solo play and two-player sessions.
- Let players use The Long Drive's vehicles and items, sourced from their own Steam installation.
- Aim to match The Long Drive's on-foot and driving physics.

## Game requirements

- **Garry's Mod** is the game players launch and the host for the gamemode.
- **The Long Drive** is an additional requirement for its real content. Its files must be read from the player's own Steam installation; game assets will not be included in this repository or release.

## Status

This repository currently contains a concept README, not a playable build. The Long Drive uses Unity/Mono and Garry's Mod uses Source, so loading its assets and matching its physics inside a GMod gamemode need a feasibility prototype. The intended Melty release must use plain Garry's Mod mod files and pass Melty's one-click checks before it can be described as ready to install.

Multiplayer capacity and the desired join paths are set at two players, with Steam invites or the Garry's Mod server browser acceptable. Hosting and joining have not been implemented or tested.
